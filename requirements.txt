# Reading screenshots and scanned runsheets. The OCR engines are the
# operating system's own — Apple Vision and Windows.Media.Ocr — so these
# are thin wrappers, not bundled ML runtimes. Measured: the whole winrt
# stack is ~1MB (winocr 0.0.15 dropped the 12MB monolithic winsdk for
# granular winrt-* packages), and on Mac pywebview already pulls pyobjc
# for WebKit. An ONNX engine would have added 60-100MB, which on the
# Windows --onefile build means slower launches.
#
# Neither exists on Linux: parsing/ocr.py raises OCRUnavailable there and
# the tests inject fake backends, so CI never needs a real engine.
