Library

Where to fetch the list of songs / presentations to match against. Auto tries ProPresenter's API first, falls back to the local folder. Loaded silently on launch and again before each parse — most operators never need to touch this.

—

OpenRouter AI

The model that reads your runsheet PDF. Leave this on Automatic and the app picks a working free one for you — the list comes from OpenRouter as you open this, so it never goes stale.

The instructions the AI follows when reading your runsheet. Most operators never need to touch this.

Template links

Runsheet Pilot matches a runsheet line to a template slide when the slide's name appears in the line — "Welcome and Connection Cards" finds the Welcome slide. When the two share no words (runsheet says Youth Arrival + Hangout, the slide is called PreLoop Youth), teach it here once.

Playlist options

For every section with a duration (e.g. 30 min sermon), a countdown timer appears in PP's Timer panel. Old [RB] timers are cleared first so re-runs don't pile up.

Higher = fewer false matches but more "ACTION NEEDED" placeholders. Lower = more confident matches but risk of wrong song.

Anonymous usage stats

Sends anonymous counts and timings — how long a parse took, how many items and sections were created, and the type of any error. Never your runsheets, song titles, media names, file names or file paths, and there is no account or device ID. Turn it off any time; it takes effect immediately.

Extras

ProPresenter doesn't always use port 50001. If the port above doesn't answer and ProPresenter is on this computer, Runsheet Pilot reads the real one from ProPresenter's own settings and switches to it. A port you typed that works is never changed.

After parsing, lists media added to your Downloads and Desktop in the last two days, and guesses which runsheet item each one belongs to. ProPresenter's API can't import media, so you still drag the file into its Media tab — but Runsheet Pilot spots it the moment you do and links it. Reads file names only, never contents.
